# Kimi Code 项目入口

开始任何项目任务前, 读取并遵守以下根目录治理文件:

1. `../constitution.md` — 项目最高优先级的安全红线与工程原则.
2. `../AGENTS.md` — 跨工具共享的项目事实, 脚本与协作约定.
3. `../KIMI.md` — Kimi Code CLI 专属能力与行为.

本文件只负责连接 Kimi Code CLI 的原生指令加载与根目录治理文件, 不复制或重新定义其中的规则.
