Bruce 仪表盘 · 卡片收起样式候选

参考 · 当前展开态 (1:1 还原)

对照 UsageHeroCard / SubscriptionCard / HourlyLineCard 源码还原的展开态基准, 数据为虚构. 点击标题行可收起.

方案 A · 标题 + 关键指标一行摘要 未采用 · 保留供对比

高度约 44pt (标题行原 padding). 信息量最大: 用量卡 = 今日 token + 成本, 订阅卡 = 最紧张额度窗口, 逐小时卡 = 当前峰值. 适合收起后仍需一眼掌握状态的默认方案; 代价是摘要口径需逐卡维护, 指标需等宽数字防抖动.

方案 B · 极简细条 (仅标题 + chevron) 未采用 · 保留供对比

高度约 30pt, 三卡收起后整面板最紧凑. 信息量为零, 纯导航; 适合「默认收起次要卡片, 只看主卡」的场景. 成本最低, 无需为每张卡定义摘要.

方案 C · 标题 + 迷你可视化 (已选定 · 最终版式)

标题与迷你图形同行: 标题居左, 图形铺满右侧剩余空间, chevron 悬停显示, 点击整行切换, 整卡约 46pt. 用量卡 = 渐变 hero 数字 + 近 7 天迷你热力图 (7 格均分铺满), 订阅卡 = 分 provider 徽章 + 5pt MeterBar (三档告警渐变), 逐小时卡 = 24 点合计迷你折线. 收起态不含成本估算.

混合示例 · 用量卡展开 + 两张收起 (方案 C 最终版式)

模拟真实使用: 主卡常开, 次要卡片收起为迷你可视化. 每张卡独立记忆状态.

Nothing 主题 · 方案 C 变体 2 (已定稿版式)

同一收起态版式套用 Nothing 语言 (字体分工对齐 NothingFont.swift): 展示数字 Doto 点阵粗体 (#4A9E5C 纯色), 卡片标题 Space Grotesk semibold, 小字 Space Mono; 面板纯黑, 卡片圆角 5 + 1px #333 边框, 无高光无阴影; 热力格直角绿阶, 徽章品牌色 16% 底 + 品牌色字母, MeterBar 阈值三色 (#4A9E5C / #D4A843 / #D71921), 底栏纯黑 + #222 发线 + Space Mono 大写按钮. 仅展示 dark, 聚焦收起态.
