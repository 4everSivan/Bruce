BRUCE DASHBOARD // NOTHING 风格优化提案

方案 A · 工业电路 (Glyph)

  • 贴近 Nothing OS 3.0 全新锁屏小部件交互规范

  • 兼顾苹果原生 macOS 桌面与 Nothing 现代审美

方案 C · 音响合成器 (Hi-Fi)

  • 致敬 Teenage Engineering OP-1 与 Dieter Rams

  • 极致的工业理性、严苛的排版模数与等宽美感
