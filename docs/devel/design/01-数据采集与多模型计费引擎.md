## 1. 简介 (Introduction)

本方案定义 `Bruce` 的核心数据引擎 —— **Core Collector**。
Core Collector 独立运行于 `core/collector/`，由纯 Rust 打造，作为高吞吐、零内存泄漏的守护采集进程。

- **业务动因**：现代开发者通常在本机多 Agent 并行开发（如使用 Claude Code 自动化重构、Codex 审查代码、Kimi Code 分析仓库、OpenCode 执行终端操作等）。每个 Agent 拥有独立的会话目录、专有的日志格式（JSONL、SQLite、增量转储）及不同的模型标记。开发者迫切需要一个统一、轻量、近实时的引擎，快速扫描本地日志并折算为统一的 Token 与美元费用指标。
- **系统定位**：作为底层数据生产引擎，向下只读扫描用户家目录下的 Agent 会话日志与云端额度接口，向上通过标准 IPC（JSON over stdio）为应用层（macOS App / Web Widget）提供强类型标准工件（Artifact）。

---

## 2. 目标与非目标 (Goals & Non-Goals)

### 2.1 目标 (Goals)
1. **多源异构会话即时扫描**：原生支持 Claude Code, Codex, Kimi Code, OpenCode, CodeBuddy, Grok, Pi, ZCode 等 8+ 主流 Agent 的日志解析；
2. **增量指纹与零冗余 I/O**：基于 `64KB Segment Fingerprint` + `mtime/size` 双重缓存策略，冷启动后二次扫描延迟低于 50ms；
3. **多模型精密计费**：内置 26 款主流大模型基准定价表（输入、输出、Cache Read 单价），支持模型别名归一化与用户自定义覆盖（Overrides）；
4. **强健的系统安全性**：对符号链接提供防环保护（Cycle Prevention），读取外部应用 SQLite 时强制 `mode=ro` 只读连接，绝不破坏宿主会话。

### 2.2 非目标 (Non-Goals)
1. **不拦截或代理模型网络流量**：不充当本地反向代理或网关，纯旁路离线审计；
2. **不修改或清理第三方 Agent 会话文件**：严禁向扫描目录执行写入、删除或格式化操作；
3. **不提供跨机器数据同步服务**：所有采集和聚合逻辑均在单机闭环。

## 3. 需求分析 (Requirements)

### 3.1 功能需求清单
- **FR-1 多源扫描**：自动探测本机 `~/.claude/`、`~/.codex/`、`~/.kimi/` 等标准路径，兼容单文件 JSONL、分片目录与 SQLite 状态库；
- **FR-2 时间窗口切片**：支持今天（Today）、过去7天（7d）、过去30天（30d）与全量（All-time）四维时间窗口聚合；
- **FR-3 维度多维交叉**：支持 `Agent × Model × Month`、`Agent × Project` 等多维聚合，生成模型分布占比与趋势数据；
- **FR-4 成本换算**：按各模型具体输入 Token、输出 Token、缓存读取 Token（Prompt Cache Read）分别乘以单价并折算为 `costUsd`。

### 3.2 非功能需求 (NFR)
- **性能指标**：冷启动扫描 10,000+ 条会话日志总耗时 < 1.5 秒；增量缓存命中时总耗时 < 80 毫秒；
- **内存开销**：单次完整采集峰值内存占用 < 35 MB，任务完成后瞬时释放；
- **架构兼容**：支持 Universal 2 二进制（`arm64-apple-darwin` 与 `x86_64-apple-darwin`）。

##### 2. 费用核算计算式
对于任意用量切片，总费用计算严格遵循以下纯函数公式：
$$\text{Cost} = \frac{\text{inputTokens} \times P_{\text{in}} + \text{outputTokens} \times P_{\text{out}} + \text{cacheReadTokens} \times P_{\text{cache}}}{1,000,000}$$
- 当模型命中用户在设置中配置的自定义覆盖项（`ModelPricingOverride`）时，优先采用覆盖单价；
- 未知新模型默认回退至通用中端基准（$1.00 / 1M in, $3.00 / 1M out），并在日志产出 Diagnostic 提示。

##### 3. 增量缓存机制与文件防环
- **分段哈希**：扫描器仅对会话文件头部及末尾 64KB 执行 SHA-256 计算，避免对数百兆历史日志全量重哈希；
- **防环保护**：维护 `visited_inodes: HashSet<(u64, u64)>`（针对 Unix 文件系统 `(dev, ino)`），当检测到重复节点或深度超过 16 层时立即切断，防止符号链接循环导致的死循环或栈溢出。

## 7. 扩展设计 (Additional Technical Design)

### 7.1 缓存持久化
- 缓存文件统一保存在 `~/Library/Caches/Bruce/collector-cache/`；
- 单会话缓存存储结构包含：`fingerprint`, `last_byte_offset`, `parsed_turn_count`, `bucket_deltas`；
- 版本迁移：内置 `PARSER_VERSION = 2` 与 `AGGREGATION_VERSION = 2`，版本升级时自动淘汰旧缓存文件并无损重算。

### 7.2 IPC 错误与降级
- 遇到个别日志行损坏或 JSON 截断：递增 `ScanStats.malformed_lines` 并平滑跳过，绝不中断整次采集；
- 遇到权限不足或外部 SQLite 独占锁冲突：产出 `ScanStats.conflict_session_groups` 诊断，保障其他正常源完整出库。
