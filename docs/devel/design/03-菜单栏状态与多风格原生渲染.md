## 1. 简介 (Introduction)

本方案定义 `Bruce` 的菜单栏状态指示系统（Menu Bar Status Item）与原生下拉仪表盘（Dashboard Panel）渲染架构。

- **业务动因**：macOS 菜单栏是用户与常驻工具交互频次最高的“一等公民”入口。然而不同用户的桌面环境差异巨大（高对比度壁纸、暗黑/明亮主题、MacBook 刘海屏空间极其拥挤等），单一维度的文字或死板图标无法满足需求。此外，下拉控制台需要承载密集的 Agent 用量折线图、多模型费用对比与订阅额度卡片，对视觉质感与渲染性能提出了苛刻要求。
- **系统定位**：位于 `apps/macos/Sources/BruceApp/Views/` 与 `apps/macos/Sources/BruceGlassSurfaceCore/`，向下消费 `BruceAppCore` 提供的聚合快照，向上驱动 AppKit 原生 NSStatusItem 与无边框 NSPanel 玻璃面板。

## 2. 目标与非目标 (Goals & Non-Goals)

### 2.1 目标 (Goals)
1. **赛博精密环形仪表 (Precision Cyber Ring Gauge)**：在 22pt 标准菜单栏高度内，提供像素级精度的多段彩色用量环、刻度线、中心核心图标/剩余量指示；
2. **多模式自适应布局**：支持 `纯图标模式 (Icon-Only)`、`紧凑数值模式 (Compact Value)` 与 `宽屏组合模式 (Expanded Trend)`，适配刘海屏空间挤压；
3. **双重先锋主题引擎**：
   - **原生液态玻璃 (Liquid Glass)**：基于系统材质的连续窗口级背景模糊（macOS 26+ `NSGlassEffectView` 与 macOS 14-25 `NSVisualEffectView` 兼容层）；
   - **Nothing 极客点阵风格 (NDot Minimalist)**：硬核红/白/黑极简点阵字型、LCD 晶体迷你仪表与 Emerald Glow 微光走势折线；
4. **低功耗与零帧率抖动**：空闲态 0% CPU 占用，菜单栏重绘仅在快照更新或分钟级心跳时触发，下拉面板动画保持 120Hz ProMotion 流畅。

### 2.2 非目标 (Non-Goals)
1. **不修改系统状态栏核心行为**：不注入私有 Dock/WindowServer 进程，严格遵循 Apple 官方 `NSStatusItem` 规范；
2. **不改变数据核心协议**：UI 层纯单向数据流渲染，严禁在 View 渲染树中触发隐式网络请求或磁盘扫描；
3. **不强占全局焦点**：面板设计为非激活式（Non-activating Panel），点击面板外部或切换至其他 App 时自动轻量淡出关闭。

## 3. 需求分析 (Requirements)

### 3.1 功能需求清单
- **FR-1 菜单栏指标自由配置**：支持选择展示当日 Token 消耗、当日费用（USD）、或最紧张 Provider 额度剩余百分比；
- **FR-2 警示色彩动力学**：额度正常时为极客白/青绿（Emerald），接近阈值（>75%）时呈现警戒琥珀黄（Amber），耗尽（>95%）或断配时呈现科技红（Neon Red）；
- **FR-3 模块化卡片流**：下拉面板按业务卡片解耦：
  - Agent 活跃概览卡（Claude, Codex, Kimi 等当前活跃状态）
  - 核心 Provider 额度卡（滑动窗口进度条、重置倒计时）
  - 24 小时 Token / 费用走势折线图
- **FR-4 折叠态交互与图表动画隔离 (Collapsible Cards & Animation Discipline)**：
  - 支持卡片一键折叠与状态记忆，收起态呈现标题与高保真迷你可视化；
  - **动画事务与图表隔离契约**：收起态迷你图表（如 `HourlyLineCard` 中的 24 点迷你折线图）必须通过 `.transaction { $0.animation = nil }` 显式阻断继承父级的折叠动画事务，杜绝 Swift Charts 在 0.25 秒高度坍缩期间触发 Mark 内部数据插值形变或拉扯；
  - **展开区裁切与转场约束**：展开内容必须附加 `.clipped()` 与 `.transition(.opacity)`，确保卡片高度折叠时由下至上整齐裁切，杜绝内部柱状图、多行折线图或进度条因提议高度变矮发生垂直挤压重绘；
  - **标题栏状态件平滑渐隐**：`CollapsibleCardHeader` 中收起态 `mini` 与展开态 `status` 统一应用 `.transition(.opacity)`，杜绝两态交替时的元素横向飞动或晃动。
- **FR-5 顶栏单卡 Tab 切换与角标融合布局 (Top-Right Tab Switcher & Badge Fusion)**：
  - **双模式并存与设置开关**：支持「纵向级联 (滚动瀑布流)」与「顶栏 Tab (单卡极简)」双模式，在设置中心「通用」面板中提供分段开关切换，持久化落盘至 `dashboard.layoutMode`（`stack` / `tabbed`）；
  - **顶栏三图标导航**：在 HUD Header 右侧提供三个等宽紧凑分段按钮（`Token 用量 chart.bar.xaxis`、`订阅配额 creditcard`、`Agent 活跃 waveform.path.ecg`），并带高亮背景滑动药丸底；呼出面板支持键盘快捷键 `1` / `2` / `3` 快速无感切卡；
  - **角标融合 (Badge Fusion)**：当活跃 Agent > 0 时，在第 3 个活跃图标右上角亮起绿色呼吸小圆点，悬停展示活跃 Agent 数量；顶栏不额外堆砌文本，维持极简；
  - **状态记忆 (Tab Persistence)**：持久化记录 `dashboard.activeCardID`，重新呼出面板时自动记忆并恢复最后浏览的卡片；
  - **方案 1 方向感知水平滑动动效 (Directional Slide)**：切卡时根据索引前后关系自动感知滑动方向（向右切卡自右向左推入，向左切卡自左向右推入），配合容器高度以系统 Spring 阻尼曲线弹性伸缩；内部既有三张卡片结构与指标样式 100% 保持原样；
  - **跨端等价性**：Windows 端在 `apps/win/src/` 同步镜像本特性，保持 SVG 几何、CSS 硬件加速水平滑动与 `%APPDATA%\Bruce\settings.json` 的完全等价。
- **FR-6 面板底栏外观切换入口 (Footer Appearance Toggle)**：
  - **位置与形态**：在底栏「刷新」按钮右侧新增一个仅图标按钮（紧随刷新、位于左半区，与右半区的「设置 / 退出」以 Spacer 分隔），图标即当前外观态（跟随系统 `circle.lefthalf.filled` / 浅色 `sun.max` / 深色 `moon`）；
  - **单击循环语义**：单击在「跟随系统 → 浅色 → 深色 → 跟随系统」间循环，循环顺序与设置中心「配色模式」分段选择器**逐字一致**，由 `AppearancePreference.next` 单一纯函数给出（以 `allCases` 声明顺序为准，避免两处顺序漂移）；
  - **单一真源与即时生效**：复用既有持久化偏好 `OnboardingConfiguration.appearanceMode`，点击即调 `OnboardingCoordinator.setAppearanceMode`（先存后生效，保存失败不变更运行态），面板与设置窗口的 `preferredColorScheme` 随之同步；
  - **可达性**：提供 `accessibilityLabel`（含当前态中文名）与 `.help` 悬停提示，并纳入底栏整体提示文案；面板隐藏期间不得引入任何持续动画或定时器（沿用 FR-4 / C044 门控契约）；
  - **跨端分歧（有意）**：外观切换为 **mac 独有能力** —— Windows 恒深色且无配色模式偏好，故 `apps/win/src/index.html` 底栏不镜像该按钮，仅在注释中登记该分歧（与「配色模式 / 钥匙串 / 外部 CLI 来源为 mac 独有能力」同口径）。
- **FR-7 顶部四色状态灯 (HUD Status Light)**：**实现状态：已实现（C100，待双端真机验收）**。
  - **形态收敛**：删除 HUD 头左侧的 `SYS.OK` 文字牌（mac `MenuBarViews.swift` Nothing/Classic 两处、Windows `index.html` 的 `#runtime-status`），顶部只保留「状态灯 + 品牌字」；品牌字在**所有主题**统一为 `Bruce`（删除 `// HUD` 后缀，Nothing 主题同时去掉 `.hud-brand` 的 `uppercase` transform，确保字面即 `Bruce`）；灯与品牌间距保持 6，右侧 Tab 切换器 / Agent 计数靠 `Spacer` 自动右对齐。
  - **四色语义与统一判定源**：状态灯为绿 / 黄 / 红 / 中性灰四色，加「刷新中」呼吸脉冲态，由单一判定源 `resolve(moduleState:subscriptions:hasData:detail:) -> (tone, reason)` 给出（`subscriptions` 为 `{status, name}` 列表）（mac 落在 `BruceAppCore`，Windows 在 `app.js` 内实现同一张映射表，双端共用一份 fixture 对拍）。映射：绿 = `fresh` / `ready`（mac）、`ok` / `fresh` / `idle`（有数据，win）；黄 = `partial` / `stale` / `authRequired`（两端同）；红 = `failed`（mac）、`failed` / `error` / `unavailable`（win）；中性灰 = `notConfigured`（mac）、`empty` 与无 artifact 首次启动（win）；刷新中 = 呼吸脉冲且底色取当前态色。`stale`（数据过期）归黄，红只留给「采集失败且无可用数据」。
  - **聚合口径（两端逐字一致）**：灯表达「数据可用性总览」，聚合「采集健康度」（mac `moduleStatuses[.agentUsage]` / win `runtime.phase`）与「订阅服务健康度」（两端 `panel.subscription.sections[].status`，同构取值 `ok` / `partial` / `error` / `empty`）两个来源，按最严重态优先 `error > warn > ok` 取并；中性灰仅在两者均无数据时出现。
  - **触碰显示原因**：状态灯挂 hover 提示 —— mac `.help(reason)` + `.accessibilityLabel(reason)`，Windows `title` + `aria-label`（迁移原 `#runtime-status` 的 `role="status"` 语义）；文案为「态名 · 具体原因」，原因按决定灯色的一侧取：采集侧决定（含与订阅侧同级）时取采集详情 —— mac `ModuleStatus.detail`，win `runtime.error` 机器码经 `RUNTIME_ERROR_TEXT` 转成的中文释义（未登记的码不外露，只显示态名）；订阅侧更严重时点名该级别的服务名（去重，以「、」连接），不挂采集侧详情。健康态显示「运行正常」、刷新中显示「正在刷新…」。
  - **边界**：卡内 LIVE 指示与订阅卡内 section / account note 保持不变，**不与顶部灯联动**；面板隐藏期间不得引入任何持续动画或定时器（沿用 FR-4 / C044 门控契约）。
- **面板规格基准**：面板宽度固定为 `440pt`，自适应高度动态计算（最大高度不超过当前屏幕高度的 80%），超出区域启用平滑弹性滚动；
- **冷启动渲染延迟**：点击菜单栏图标至面板完全展开渲染时间 < 16 毫秒（首帧即见最新快照）；
- **内存安全**：AppKit 窗口与 SwiftUI Hosting Controller 之间杜绝强引用循环。

## 4. 总体架构与渲染拓扑 (Architecture)

```text
NSStatusBar (系统菜单栏)
└── NSStatusItem (Bruce 状态项)
    └── PrecisionRingGaugeView (CoreGraphics / SwiftUI 仪表)
        ├── 刻度底环 (Track Ring)
        └── 动态进度弧 (Dynamic Usage Arc, 纯净通透无中心点)

DashboardPanel (无边框浮动 NSPanel)
└── DashboardGlassPanelController (AppKit 宿主)
    ├── NativeSurfaceView (系统材质承载层: NSGlassEffectView / NSVisualEffectView)
    └── NSHostingView<MenuBarDashboardView> (SwiftUI 业务渲染层)
        ├── PanelHeaderView (时间、总消耗概览)
        ├── QuotaCardsStack (Provider 额度进度条)
        ├── AgentUsageStack (各 Agent 用量与模型分布)
        ├── TrendChartSection (折线趋势图)
        └── PanelFooterBar (刷新 / 外观切换 / 设置 / 退出入口)
```

#### 现行设计规则

##### 1. 赛博精密环形仪表 (`PrecisionRingGaugeView` / `MenuBarStatusItemController`) 规格契约
- **外径尺寸**：`18pt × 18pt`（居中对齐 22pt 状态栏）；
- **线宽与形态**：外轨宽度 `1.5pt`，内圈通透留空（中心不绘制任何微粒像素），保持极简通透质感；
- **着色与警戒状态**：
  ```swift
  let statusColor: Color = switch currentRatio {
  case 0.00..<0.70: Color(hex: "#00E599") // 翡翠绿 (Healthy)
  case 0.70..<0.90: Color(hex: "#FFB800") // 警示黄 (Warning)
  default:          Color(hex: "#FF3366") // 霓虹红 (Critical)
  }
  ```
- **零额度告警**：配额耗尽（`<=0`）时在 12 点钟顶端绘制单一微型警示红点，避免影响圆环主体通透度；
- **刘海屏自适应**：当系统检测到处于 MacBook 内置显示屏且可用空间不足时，自动触发 `iconOnly` 紧凑模式，隐藏外挂数值标签，仅保留纯环形图标。

##### 2. 窗口级材质承载层架构 (`DashboardGlassPanelController`)
彻底摒弃在单个卡片上叠加多层仿玻璃塑料背景的做法，将系统级材质作为统一底板：
```swift
final class DashboardGlassPanelController: NSViewController {
    private let surfaceView = NativeSurfaceView()
    private var hostingView: NSHostingView<MenuBarDashboardView>?

    override func loadView() {
        let root = NSView()
        root.wantsLayer = true
        surfaceView.autoresizingMask = [.width, .height]
        root.addSubview(surfaceView)
        self.view = root
    }
}
```
- **macOS 26+**：采用 `NSGlassEffectContainerView` 搭配流体高光与系统光感；
- **macOS 14-25**：回退至 `NSVisualEffectView(material: .popover, blendingMode: .behindWindow)`；
- 内部 SwiftUI 卡片背景全部设置为 `Color.white.opacity(0.04)`（暗黑）或 `Color.black.opacity(0.02)`（明亮），配合 `0.5pt` 细微半透明描边，实现晶莹通透的呼吸感。

##### 3. Nothing 风格点阵引擎
针对追求极简硬核科技的用户，内建 Nothing 风格主题：
- **字体契约**：数字与标题采用 `NDot 57` 点阵等宽字型，辅助信息采用 `Space Mono`；
- **点阵 LCD 仪表**：将连续圆环离散化为 16 段矩阵点，每段代表 6.25% 刻度；
- **Emerald Glow 微光走势**：折线图采用无填充的 1pt 纤细线段，并在折点处绘制 2pt 发光微粒。

##### 4. 底栏外观切换入口 (`actionFooter` 外观按钮) 契约
- **唯一真源**：外观偏好只存于 `OnboardingConfiguration.appearanceMode`（`AppearancePreference`）；底栏按钮与设置中心「配色模式」是同一偏好的两个入口，禁止引入第二份状态或独立持久化键；
- **循环顺序**：`AppearancePreference.next` 是唯一的循环定义（跟随系统 → 浅色 → 深色 → 跟随系统），以 `allCases` 声明顺序实现；设置中心分段选择器的选项顺序必须与之一致，变更任一处必须同步另一处；
- **先存后生效**：点击经 `OnboardingCoordinator.setAppearanceMode`，持久化失败时不改变运行态外观（与设置中心同一失败语义）；
- **图标即状态**：按钮图标必须反映当前外观态（`circle.lefthalf.filled` / `sun.max` / `moon`），不得使用与当前态无关的固定图标；图标为 SF Symbols，随底栏既有 `.labelStyle(.iconOnly)` 渲染；
- **面板显隐门控**：该按钮为无状态瞬时控件，不得引入持续动画、定时器或后台任务（沿用 FR-4 / C044 契约）；
- **跨端口径**：Windows 恒深色、无配色模式偏好，底栏有意不镜像该按钮；该分歧在 `apps/win/src/index.html` 底栏注释中登记，不得静默扩散为「未对齐缺陷」。

## 6. 扩展设计 (Additional Technical Design)

### 6.1 Web Widget 嵌入式组件契约 (`apps/widget/`)
- 为支持 Daimon / Kimi Blueprint 桌面嵌入，在 `apps/widget/` 提供单文件 HTML/CSS/JS 小组件；
- 小组件通过解析 `data.main`（与 macOS App 共享相同的 `AgentUsageArtifact` 契约），实现桌面背景级实时用量监控。

### 6.2 焦点管理与关闭策略
- **失焦关闭**：监听 `NSEvent.addGlobalMonitorForEvents(matching: [.leftMouseDown, .rightMouseDown])`，点击面板以外区域即刻触发平滑动画关闭；
- **Esc 快捷键响应**：面板作为第一响应者时，按下 Esc 键立即收起。
