# 网络出口国家校验设计

Bruce 可以为订阅服务商设置预期出口国家和专用代理端口，在查询额度前探测线路。国家不匹配、探测失败或受管配置无效时，Collector 阻断本次查额，并在结果中记录出口状态。该机制的保护范围是订阅额度查询；本地会话扫描及其他网络操作不因此自动受到保护。

## 目标与边界

每个国家分组包含国家代码、专用端口和服务商列表。一个服务商只能归属于一个国家组，同一服务商的账号共享这条规则。分组模型只管理路由归属，不保存或删除订阅凭据。未加入分组的服务商沿用原有查询路径。

专用端口必须由用户绑定到固定节点。探测连接与后续查额连接虽然使用同一回环代理端口，仍是不同连接；探测只能反映探测时的出口，无法保证代理或上游节点在两次连接之间不发生变化。Bruce 不替用户验证代理的固定节点配置。

## 分组与输入

新增国家时，配置模型去除输入两端空白并转为大写，拒绝无效或重复的国家代码。把服务商分配到新组时，模型先检查目标组存在，再移除该服务商在其他组的归属并加入目标组。移出服务商或解散国家组只改变分组关系。

端口允许暂时为空，但不能是 0。端口发生变化时，上次线路测试结果被清空。构造 Collector 输入时，每个受管服务商对应一条 `egressRules` 规则，含 `country` 和 `port`；尚未填写端口时仍传入 `null`，使其被判为无效受管配置，而不是误当作未分组。

## 查额前的决策

Collector 在检查取消状态、解析凭据、寻找服务商并取得网络许可后读取对应规则。没有配置规则时，直接调用服务商查询；规则存在但格式、国家代码或端口无效时，返回 `EGRESS_CONFIG_INVALID`，不调用服务商查询。

有效规则通过指定回环代理端口请求 `https://cloudflare.com/cdn-cgi/trace`。请求超时为 3 秒，响应上限为 4096 字节；非 200 响应或传输失败归为探测失败。响应必须包含可解析的 IP 和有效国家代码，重复字段或无效值会导致出口未知。系统只向后续结果传递脱敏地址：IPv4 保留前两段，IPv6 保留前两组。

一次刷新内，同一端口的并发查询共享一次探测结果，不同端口分别探测。对于成功解析的结果，若观察到 `CN` 而预期不是 `CN`，返回 `EGRESS_CN_DIRECT`；否则国家不同时返回 `EGRESS_COUNTRY_MISMATCH`。匹配时，Collector 使用同一个专用端口包装 HTTP 客户端，再调用服务商查额接口。

例如，Codex 受管规则为 `JP` 和端口 `18081`：探测为 `JP` 时可进入查额；探测为 `US` 时阻断查额并记录预期与观察国家；探测失败时同样阻断。若配置中该端口为空，也不会退回未分组路径。

## 结果与提醒

探测匹配时，服务结果可附带 `allowed`、预期和观察国家及脱敏地址；阻断时附带 `blocked`、原因代码及可获得的国家和脱敏地址。探测失败、国家未知、配置无效、国内出口和国家不匹配分别使用不同原因代码，供界面区分原因。

macOS 的出口提醒评估器从 artifact 的 `services` 中提取 `egress.status` 为 `blocked` 的条目。全量刷新保留全部阻断条目；定向刷新只保留能够映射到目标服务商的条目，无法确定归属的条目不会被猜作目标。调度器维护已阻断的服务标识，用于区分新增阻断和持续阻断。

> **注意**：以上为现有源码和设计定义的行为说明。完整快照合并、设置持久化、失败重试与跨平台覆盖仍需结合各自实现核对；不能据此推断设备或真实代理环境的验收结果。
