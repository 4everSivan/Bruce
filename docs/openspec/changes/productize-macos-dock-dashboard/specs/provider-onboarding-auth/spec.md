## ADDED Requirements

### Requirement: 本机依赖与账号状态扫描

系统必须 (MUST) 在首次引导和设置页中扫描已启用模块所需的本机依赖、会话位置和登录状态. 扫描必须为只读操作, 并且不得把凭证内容展示在界面、日志或诊断结果中.

#### Scenario: 扫描可用依赖

- **WHEN** 用户首次打开应用或主动重新检查环境
- **THEN** 系统分别报告 Python 3、GitHub CLI、相关本机会话、私有 GitLab 地址和网络可达性的可用状态

#### Scenario: 发现缺失依赖

- **WHEN** 扫描发现某模块缺少必需依赖
- **THEN** 系统将该模块标记为待配置, 提供安装或配置说明, 且不尝试执行对应 Collector

#### Scenario: 读取本机认证文件

- **WHEN** 系统为判断登录状态读取受支持应用的认证文件
- **THEN** 系统仅提取判断状态所需的最小字段, 不修改原文件, 也不把原始凭证写入快照

### Requirement: 应用内官方登录窗口

系统必须 (MUST) 为支持 OAuth 或设备授权的服务提供应用发起的登录窗口或系统授权会话, 并将用户导航到服务官方登录页面. 应用不得收集或代理用户密码.

#### Scenario: 用户登录支持 OAuth 的服务

- **WHEN** 用户在应用中选择连接支持 OAuth 的服务
- **THEN** 系统打开官方授权页面, 展示请求的权限范围, 并在授权回调成功后记录该服务为已连接

#### Scenario: 用户取消登录

- **WHEN** 用户关闭登录窗口、拒绝授权或授权流程超时
- **THEN** 系统保持该服务未连接状态, 清理临时授权状态, 并允许用户稍后重试

#### Scenario: 服务不支持应用 OAuth

- **WHEN** 用户连接仅支持 PAT、API key 或既有 CLI 登录态的服务
- **THEN** 系统提供明确的手动配置入口或官方 CLI 登录引导, 且对输入值使用安全字段

### Requirement: 统一授权确认与细粒度控制

系统必须 (MUST) 在首次启用自动采集前提供一次统一授权确认, 清楚列出将扫描的本机位置、将访问的外部服务、自动刷新频率和可能发生的令牌续期. 用户必须能够按服务撤销授权或禁用采集.

#### Scenario: 用户确认统一授权

- **WHEN** 用户审阅授权摘要并确认启用选定服务
- **THEN** 系统仅为选定服务启用凭证访问、自动续期和默认 30 分钟刷新

#### Scenario: 用户撤销单个服务

- **WHEN** 用户在设置中撤销某个服务的授权
- **THEN** 系统停止该服务的新采集和令牌续期, 删除应用自己保存的对应 Keychain 项, 且不影响其他服务

### Requirement: Keychain 凭证存储

系统必须 (MUST) 将应用持有的访问令牌、刷新令牌、PAT 和 API key 存储在 macOS Keychain 中. 凭证不得写入仓库、普通配置文件、Artifact 快照、Widget 数据或非脱敏日志.

#### Scenario: 保存新凭证

- **WHEN** 登录流程或手动配置返回有效凭证
- **THEN** 系统将凭证保存到以服务和账号范围区分的 Keychain 项, 并仅在界面中显示脱敏状态

#### Scenario: Collector 请求凭证

- **WHEN** 某次采集需要访问凭证
- **THEN** 系统在任务运行期间从 Keychain 读取最小必要凭证, 通过受控进程输入传递, 并在任务结束后释放内存引用

### Requirement: 自动续期与重新授权

系统必须 (MUST) 在用户完成统一授权后, 对支持刷新令牌的服务自动续期访问令牌. 若续期失败或服务撤销授权, 系统必须暂停该服务并要求用户重新授权, 不得无限重试.

#### Scenario: 访问令牌即将过期

- **WHEN** 已授权服务的访问令牌达到安全续期窗口且存在有效刷新令牌
- **THEN** 系统在下一次采集前完成一次自动续期, 验证响应后原子更新对应 Keychain 项

#### Scenario: 自动续期失败

- **WHEN** 服务返回无效刷新令牌、授权撤销或不可恢复的认证错误
- **THEN** 系统停止该服务的自动重试, 保留最后成功快照, 并在应用内提示重新登录

#### Scenario: 临时网络故障

- **WHEN** 续期因超时或临时网络错误失败
- **THEN** 系统按有限退避策略重试, 且不得把临时故障错误地标记为永久授权撤销
