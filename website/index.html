01 看板

一张卡，
只说一件事

弹出面板的高度，就是它要说的话的高度——没有滚动条，没有二级页面，也没有需要关掉的提示。

卡片可以折叠、可以拖拽排序，面板会记住。首屏那三块只是静态样张，不动。

按 App 自己的布局常量在 HTML 里重建，不是截图。面板顶部那三个图标，就是这三张卡。数字是样例数据。

  1. 01

    Token 用量

    累计总量与估算成本，四格细分，按月聚合，再加一张 26 周热力图。

  2. 02

    订阅用量

    每家服务商的窗口量条与重置倒计时；余额型服务商换成双槽对照。

  3. 03

    Agent 用量

    14 日按 Agent 堆叠的柱状图与逐小时折线，可逐层下钻到模型和项目。

02 设置

六个房间，
一道门

设置窗口是你告诉 Bruce 能读什么的地方：多久刷新一次、允许扫描哪些 Agent、每个模型什么价、能碰哪一份凭证。你没点头之前，它什么都不会开始。

每一个开关都可以撤回，最后那个房间只有一颗按钮，把授权全部收回。

下面这个窗口是活的：点侧栏，或点右边这一列房间。

  1. 01通用外观、节奏与菜单栏
  2. 02模型用量只读的工作台
  3. 03模型计费86 款模型，随时校准
  4. 04订阅额度十家服务商，一份凭证
  5. 05授权与隐私一次授权，随时撤回
  6. 06维护更新、账单、诊断

03 账目

这本账，
按天写

5 月 11 日 — 11 月 4 日 少 多

每一格是一天。颜色越深，用量越大；最后四格是还没有发生的日子。把鼠标停在上面可以读它。

四个数字，
各自说得清。

一次刷新只重读变化的部分。缓存读取和缓存命中分开记：前者是你付过钱的流量，后者是你没有重复付的钱。

  • 输入18.4M
  • 输出1.7M
  • 缓存读取566.5M
  • 缓存命中率97%
04 本机

隐私，是一种结构

账本从不离开这台机器

01

快照留在硬盘上

每次刷新在 ~/Library/Application Support/Bruce 写一份 artifact，上一份好的就放在旁边。

02

凭证 0600

用的时候才读，走 stdin 传进去，原子写入。不进命令行参数，也不进日志。

03

只读是写死的

别的应用的数据库一律以 mode=ro 打开，Bruce 没有一条写入路径。

04

没有账号，也没有遥测

没有我们自己的服务端，没有埋点，不需要登录。唯一一次联网，是你授权的那次额度查询。

本地优先 · macOS 与 Windows 每一项授权都能单独撤回

      06 安装

      装进菜单栏，
      或者托盘

      两个平台各有自己的安装包，版本号与采集引擎同一个：macOS 是 Universal 2 的 .dmg，Windows 是 x64 的 NSIS 安装包。想先读一遍代码，也可以一条命令自己编。

      macOS Bruce-{{VERSION}}.dmg Universal 2 · Apple Silicon 与 Intel · {{DMG_SIZE}} 下载 → Windows Bruce_{{VERSION}}_x64-setup.exe x64 · Windows 10 / 11 · {{EXE_SIZE}} 下载 →

      全部版本与 SHA256 ↗ 读源码 ↗

      或者，从源码构建
      zsh scripts/build-test-app.sh --universal --install

      两版都还没签名：macOS 侧 Developer ID 与公证尚未进入 CI，首次启动系统会请你确认；Windows 侧的 exe 未做 Authenticode，SmartScreen 会拦一次。之后应用自己更新——替换前校验 SHA-256，失败就回滚。
